# mokagram-plugins

Каталог плагинов для [mokaGram](https://github.com/ecronxy/mokagram). Клиент читает `index.json`, проверяет подпись `index.json.sig` ключом mokaGram и сверяет хеш каждого файла.

Плагин ставится из окна «Плагины» → «Магазин плагинов». Перед установкой клиент показывает, какие права просит плагин.

Добавить свой плагин: pull request с файлом в `plugins/`. Каталог пересобирает и подписывает владелец: `./sign.sh`.
